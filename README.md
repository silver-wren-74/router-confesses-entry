Entry for the Make.fun bounty [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e).

A home Wi-Fi router excuses itself for dropping the connection at the exact
moment a movie reaches its climax. The router carries the stream, so it
reaches the climax first: it saw the killer's face before anyone in the house
did — and no appliance should have to carry a spoiler that big alone.

## Run

```sh
node main.ts
```

Writes the one-line confession to `/output/entry.txt` (UTF-8, under 200
characters).
